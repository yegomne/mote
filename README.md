# 태양의 유산 · SOLAR RELIC

모바일 웹에서 즐기는 독자적인 고대 사원 매치3 게임.

## 원작에서 이어지는 101~200단계

100단계의 보물상자를 열면 **같은 게임 화면**에서 101단계가 시작된다. 원작의 8×8 캔버스 보석판·교환 조작·낙하 연쇄·특수돌·6토템·이펙트·효과음을 그대로 사용하고 화면 위에 전투를 더했다. 별도 전투 페이지와 중복 퍼즐 엔진은 제거했다.

10개 지역과 100개 전투 단계에서 슬라임부터 드래곤까지 진행한다. 초반 슬라임은 3~5마리 무리로 나오며 에너지바에 무리 전체 체력이 표시된다. 다른 몬스터도 이전보다 체력을 높였다. 물·대지·바람 토템을 순서대로 찾아 9토템을 완성한다. 몬스터는 마법마다 약점과 저항이 있고, 승리 코인으로 장비·연계 스크롤·새 토템 강화를 산다. 160단계부터 보스 2연전, 200단계는 3연전이다. 이동 횟수와 전투 시간 제한은 없다. 몬스터는 활동 시간 14~21초마다 반격한다. 보석 연쇄·일시정지·상점·도움말 중에는 반격 시간이 멈춘다. [101~200단계 설계](REALM_DESIGN.md)

105·115·125단계를 이겨 토템을 열면 다음 전투부터 물·대지·바람 보석이 차례로 추가된다. 물은 유리 같은 물방울, 대지는 균열이 있는 돌, 바람은 잎맥이 있는 나뭇잎으로 그려 작은 화면에서도 형태로 구분한다. 이미 진행한 저장 기록도 보석 해금을 복구한다. 새 보석은 시작 보드와 재배치 보드에 각각 최소 5개씩 배치한다. 전투 안내는 보석판 밖의 전투 장면에 표시한다.

101~200단계의 전투 배경과 여정 지도는 몬스터 및 지역에 따라 바뀐다. 지도에는 몬스터 초상, 진행 경로, 최고 별점과 잠긴 길을 보여준다. 다음 단계가 같은 몬스터면 1★, 다른 몬스터면 2★, 지역 보스나 새 지역이면 3★가 필요하다. 승리 뒤 남은 생명력이 70% 이상이면 3★, 35% 이상이면 2★, 그 아래면 1★이며 최고 기록을 유지한다. 전투 중에도 지도 버튼으로 확인할 수 있다.

같은 색 연속 마법 외에 **특수돌 공명 공격**이 있다. 한 턴에서 특수돌이 실제로 터지고 그 턴 점수가 기준 이상이면 추가 공격이 한 번 나간다. 기준은 지역이 진행되며 높아지고, 특수돌의 종류·개수와 초과 점수·장비에 따라 피해량이 커진다.

이세계 상점은 장비 6부위 × 4종, 각 장비 강화 +5, 그림 연계 스크롤 8종으로 확장했다. 구입한 장비를 장착하면 마법사 그림 위에 종이인형 방식으로 겹쳐 보이고 능력치가 전투에 적용된다. 스크롤은 상점 그림과 연계 공격 그림 연출을 가진다. [코인 경제 시뮬레이션](ECONOMY_SIMULATION.md)은 기존 전체 구매 후 약 16,581코인이 남던 구조와 새 구매 경로를 비교한다. [추가 그림 프롬프트](ART_PROMPTS.md)에 제작 기록을 남겼다.

검증: `node test-engine.mjs`, `node test-realm.mjs`, `node scripts/qa-realm.mjs`. 390×844, 390×667, 360×640 휴대폰 화면에서 전투·보석판·조작 버튼이 함께 보이는지 검사했다. 저장은 기존 1~100단계 기록에 이어진다.

2026-10-23 업데이트: 토템 Lv.2부터 3연속 1.5배 토템, 묵직한 투사체·폭발·파편·굵은 번개, 배경음악과 새로운 오디오 엔진, 목표 유형 10종으로 100개 스테이지 개편. [전체 레벨 설계](LEVEL_DESIGN.md)

## 사운드 v3

외부 음원 없이 Web Audio로 만든 독자적인 사원 음악, 박자에 맞춘 저음 타악기·패드·멜로디, 보석 파열음, 초능력별 음색, 3연속 각성 사운드, 스테레오 이동, 컨볼루션 잔향을 사용한다.

전체·효과음·음악 음량 별도 저장. 기본 86% / 92% / 32%. 첫 터치나 키 입력으로 재생을 시작하며 브라우저 자동 재생 정책을 따른다. 마스터 컴프레서와 리미터로 겹치는 소리를 조절한다. 효과 줄이기 설정과 음소거를 보존한다.

`node test-audio.mjs`: 여섯 토템, 각성, 음악 스케줄링, 음소거·음량 그래프를 검증했다. 모의 그래프에서 560개 음성 이벤트 실행. 실제 브라우저에서 미리듣기·게임 재생 시 오류 없음. 상업 출시 품질을 인증한 것은 아니며 기기별 청감·지연·장시간 밸런스 평가는 필요하다.

효과 수량처럼 정수만 가능한 항목은 1.5배 계산 후 올림한다. 보석 파괴 범위는 원래 유효 타일 수의 1.5배로 확장하되 전체 보드 64칸을 넘지 않는다.

## 난이도와 속성 연출 개편

100단계는 이동 제한 없이 시간제로 진행한다. 목표 점수·수정·특수 보석·봉인 강화, 분산 봉인 배치, 피버 충전 2.2→0.85/보석, 연쇄 점수 상한 8→4배. 9단계 무료 연습 재배치 제거. 강화는 선택이며 1.5배를 필수 클리어 목표로 요구하지 않는다.

불덩이는 매번 임의의 서로 다른 중심을 선택하고 직전 발동 중심을 피한다. 불은 화염·연기·파편, 천둥은 폭풍·번개·지연 천둥, 나머지는 비취/태양/달/시계로 분리했다. 사용자가 조정한 soundscape.mjs와 음량 저장 키는 유지했다.

번개는 이동한 보석을 중심으로 반경 안의 사방에 분산 감전한다. Lv.2 이상 3연속이면 반경 +0.6칸, 대상 수 1.5배(올림). 어떤 단계에도 이동 횟수 제한은 없다.

## 종료 보너스

클리어 또는 시간 종료 시 남은 특수 보석을 순서대로 발동하고 연쇄로 점수를 합산한 뒤 결과를 판정한다. 중복 발동을 막고 종료 중 입력과 시간을 정지한다. 보너스로 전체 목표를 달성한 경우 성공으로 인정한다. 마지막 보너스가 끝나기 전에 별·보상·최고 점수를 확정하지 않는다. 실제 브라우저에서 남은 특수 보석 자동 발동 +1,200점과 최종 18,150점 합산을 확인했다.

검증 추가: test-targets.mjs 960가지 중심/레벨/연속 감전 범위, test-finale.mjs 150가지 종료 연쇄, test-balance.mjs 720회 정책 비교 모의 게임. 모의 난이도는 고정 판단 시간과 장별 토템 레벨을 가정하며 실제 유저 승률을 뜻하지 않는다.
